# Python Strings

## Explanation

A string is a sequence of characters enclosed within single quotes, double quotes, or triple quotes.

Strings are commonly used to store and process text in Python.

## Problem Statement

Write a Python program that accepts a string from the user and demonstrates basic string operations such as indexing, slicing, concatenation, and repetition.

## Features

* Accepts a string from the user
* Displays the complete string
* Demonstrates string indexing
* Demonstrates string slicing
* Demonstrates string concatenation
* Demonstrates string repetition

## How It Works

The program reads a string and performs basic operations on it.

For example:

* Indexing accesses an individual character.
* Slicing extracts a portion of a string.
* Concatenation joins strings together.
* Repetition repeats a string multiple times.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Read a string from the user.
3. Display the string.
4. Access the first character using indexing.
5. Extract part of the string using slicing.
6. Demonstrate concatenation.
7. Demonstrate repetition.
8. End the program.
